# ECG heartbeat classification with a 1D CNN

Leakage-aware, imbalance-aware evaluation components from an MSc machine
learning project on MIT-BIH-derived heartbeat segments.

## Reported result from the original experiment

- 109,446 beats mapped to five AAMI EC57 classes
- 94.9% held-out accuracy, 0.80 macro-F1 and 0.991 macro ROC-AUC
- stratified five-fold macro-F1: 0.807 ± 0.070
- MLP baseline: 0.77 accuracy and 0.23 macro-F1

These are preserved assessment results, not outputs generated by the compact
portfolio reconstruction in this repository. Raw data and trained weights are
not committed.

## What is executable here

`ecg_classifier/evaluation.py` implements per-class sensitivity/specificity,
macro ROC-AUC and cross-validation that fits the scaler *inside each fold*.
The unit tests use synthetic data so CI stays fast and licence-safe.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

## Reproduction path

1. Obtain the licensed/authorised heartbeat dataset.
2. Map labels to AAMI EC57 classes and retain the original split manifest.
3. Search filters, kernel size, dense width, dropout, L2, activation and
   learning rate using validation macro-F1.
4. Refit preprocessing within every fold and publish per-class metrics.

The deliberate limitation is that no reported score is silently recreated from
synthetic data.
